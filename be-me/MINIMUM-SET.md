# ✅ Minimum test set — 11 files

The smallest amount of art that produces a real, working avatar creator you
can click around in. Everything here is for the **kid** build only; other
builds come later.

Render each one, save it to the path listed, then run:

```bash
node tools/normalize.js --body kid
node tools/preview.js --body kid
```

- [ ] 8. mouth — small closed smile
- [ ] 9. mouth — open happy grin
- [ ] 10. hat — red baseball cap

**Three bodies** proves outfit switching. **Two each of hair, eyes and
mouths** proves the layers fit and swap. **One hat** proves accessories
stack on top. **One background** completes the picture.

Bodies go in `incoming/bodies/kid/`. Everything else is shared across all
builds, so it goes straight in its own folder — you never remake it.

Filenames don't matter — any name works, and it becomes the label players
see in the game. Sizes don't matter either.

## If something looks off

Run `node tools/preview.js --body kid --guides` to see the skeleton lines.
Then it's one number in `tools/proportions.json` — `widthPct` for size,
`offsetY` to nudge up or down — and re-run. Never a redraw.

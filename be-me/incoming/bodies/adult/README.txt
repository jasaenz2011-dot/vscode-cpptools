DRAW HERE — bodies / adult
===========================

Body AND clothing rendered TOGETHER as one piece — that is what makes the
clothes actually fit. One file = one complete dressed character:
bald head, blank face, arms down, head to feet.

Vary the skin tone and the outfit across files. Each is a choice players get.

Get the prompt written for you:
    node tools/prompt.js bodies "medium brown skin, white tee, tan cargo shorts"

TARGET: 6 files

SIZE: any. Any dimensions, any crop, any empty space around it.
Transparent background. Any filename — it becomes the label players see.

Then run:  node tools/normalize.js

DRAW HERE — hair
===============

Hairstyles, rendered as if worn with a hollow gap where the head goes. Drawn ONCE — automatically refitted to every body build. Render each color you want as its own file.

TARGET: 10 files

SIZE: any. Any dimensions, any crop, any empty space around it.
Transparent background. Any filename — it becomes the label players see.

Get the prompt written for you:
    node tools/prompt.js hair "what you want"

Then run:  node tools/normalize.js

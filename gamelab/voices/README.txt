Piper TTS voices go in this folder.

1. Install Piper on the server:  pip install piper-tts
2. Download voices (each is a pair: .onnx + .onnx.json) from
   https://huggingface.co/rhasspy/piper-voices
   Good classroom starters:
     en_US-lessac-medium      (clear neutral voice)
     en_US-ryan-high          (deeper voice)
     en_US-amy-medium         (brighter voice)
     en_GB-alan-medium        (British accent)
3. Drop both files for each voice here. The Voice tool lists every
   .onnx it finds — no restart needed.
